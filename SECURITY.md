# Security policy

Please do not report security problems in public issues.

Report them privately with GitHub's "Report a vulnerability" button in the repository's Security tab. We will answer as soon as we can; this is a research release maintained on a best-effort basis, so there is no guaranteed response time.

Only the latest commit on `main` is supported. The backend and frontend are a demo application and are not meant to run as a public production service without your own review.
